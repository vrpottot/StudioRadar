# Как проверить новый поиск StudioRadar

Эта ветка меняет поиск заказов. На рабочем сайте изменения появятся только после отдельного развёртывания.

## 1. Получить тестовую копию

Установите Node.js 24 LTS и Git. В терминале:

```bash
git clone --branch codex/direct-orders-cis https://github.com/vrpottot/StudioRadar.git StudioRadar-ai-test
cd StudioRadar-ai-test
npm ci
npm ci --prefix backend
npm ci --prefix ai
npm ci --prefix frontend
```

Можно скачать ZIP этой ветки через GitHub → Code → Download ZIP; тогда начните команды с установки зависимостей внутри распакованной папки.

## 2. Проверить правила без расходов API

```bash
npm test --prefix ai
npm run build --prefix frontend
```

Ожидается 33 успешных теста и успешная сборка. Тесты подставляют ответы провайдеров: они проверяют правила, а не наличие заказов в интернете.

## 3. Указать действующие ключи

Скопируйте корневой `.env.example` в `backend/.env` и заполните:

```dotenv
PORT=8001
EXA_API_KEY=ваш_ключ_Exa
TAVILY_API_KEY=ваш_ключ_Tavily
GEMINI_API_KEY=ваш_ключ_Gemini
Google_api=
```

Достаточно одного поискового провайдера, но для совместного поиска нужны оба. Для квалификации вместо Gemini можно указать `OPENROUTER_API_KEY` и `OPENROUTER_MODEL`. Не публикуйте `.env` и не отправляйте ключи в чат. Используйте новые действующие ключи, а не значения из workflow репозитория.

## 4. Проверить реальный поиск в интерфейсе

```bash
npm run dev
```

Откройте **http://localhost:5173**, затем **Источники → Искать во всех источниках**. Дождитесь завершения: выполняется несколько десятков запросов, это занимает время. Логи backend в терминале показывают ход проверки.

У найденных заказов проверьте ссылку на исходный пост/вакансию и соответствие сфере. В Telegram требуется явно указанный бюджет проекта от 900 000 RUB. Без суммы, с бюджетом «до», зарплатой или другой валютой пост отбрасывается. В остальных источниках неизвестный бюджет допустим и не заменяется придуманной суммой.

Кнопка запускает реальные платные API. Один запуск выполняет 36 поисковых заданий, до 72 обращений к Exa/Tavily и до 48 квалификаций LLM. При активных пайплайнах работает существующий часовой планировщик.

## 5. Необязательная проверка только через терминал

Вместо интерфейса можно вызвать реальный поиск без сохранения найденных лидов:

```bash
# macOS/Linux
RUN_LIVE_HUNT=1 node ai/test_hunt.js
```

```powershell
# Windows PowerShell
$env:RUN_LIVE_HUNT = '1'
node ai/test_hunt.js
```

Это тоже расходует квоты. Нулевой результат возможен: нужны прямой открытый проектный запрос, целевая страна/сфера и подтверждённая дата публикации за последние 30 дней. Закрытые Telegram-группы и страницы LinkedIn/Facebook за авторизацией поисковым API недоступны. Не обещается полный охват площадок.

На момент подготовки ветки прошли офлайн-тесты и сборка; живые запросы не запускались из-за отсутствия настроенных ключей в рабочей среде.
