# StudioRadar AI — B2B Lead & Order Intelligence

Интеллектуальный радар и поисковик прямых коммерческих B2B-заказов и тендеров для студий компьютерной графики, 3D/2D моушн-дизайна, CGI и видеопродакшна.

## Текущий поиск прямых заказов

Поиск через **оба Exa и Tavily** по публичным публикациям HH (включая региональные домены), Telegram, LinkedIn и Facebook. Закрытые группы и страницы за авторизацией не сканируются. Фриланс-биржи, тендеры, предложения исполнителей, новости о завершённых кампаниях и штатный найм исключены.

- Все 9 отраслей и 5 услуг из `ai/sources.js`; Россия и СНГ. Акцент страны и услуги в поисковом запросе меняется ежедневно, квалификатор проверяет полный список.
- HH: явный запрос компании на студию/подрядчика для проекта. Удалённая вакансия или ГПХ сами по себе не подходят.
- Telegram: **явный бюджет проекта от 900 000 RUB**, подтверждённый точной цитатой. Бюджет «до», месячная зарплата, неизвестная сумма и другие валюты отклоняются. Автоматического пересчёта валют нет.
- Для остальных площадок минимальный бюджет не задан; неизвестный бюджет отображается как «Не указан».
- Нужны цитаты запроса, страны и даты публикации; заказ должен быть открыт и опубликован за последние 30 дней. Это консервативный фильтр: отсутствие доказательств означает пропуск кандидата.
- Один запуск: 36 поисковых заданий (4 площадки × 9 отраслей), до 72 обращений к поисковым API, до 48 квалификаций LLM, до 20 лидов. Учитывайте квоты провайдеров; автоматический поиск работает раз в час при активных пайплайнах.
- Генеративного резервного поиска без источников нет. Повторные URL не добавляются. Старые записи не удаляются с диска при смене политики, но нецелевые источники скрываются из выдачи.

Для работы нужны `EXA_API_KEY` и/или `TAVILY_API_KEY`, а также `GEMINI_API_KEY` или `OPENROUTER_API_KEY` в `backend/.env`. Используйте свои действующие ключи; в этот набор изменений ключи не включены.

```bash
npm test --prefix ai        # 33 офлайн-проверки, без расходов API
npm run build --prefix frontend
# Платный smoke-test по реальным источникам, только при настроенных ключах:
RUN_LIVE_HUNT=1 node ai/test_hunt.js
```

### Модуль `ai/` (Изолированный ИИ-движок)
Модуль инкапсулирует всю работу с нейросетями, поисковыми API и веб-скрапингом. Экспортирует единую функцию `huntOrders(options)`, которую вызывает бэкенд.

- `index.js` — главная точка входа, оркестрация поиска и экспорта `huntOrders()`.
- `search.js` — поиск по открытому вебу через Tavily Search API и Google Gemini Search Grounding.
- `fetchPage.js` — загрузка веб-страниц, очистка разметки и извлечение текста через Cheerio.
- `classify.js` — фильтрация спама/резюме и нейросетевая квалификация («это заказ или нет»).
- `extractContacts.js` — парсинг и валидация телефонов, email, Telegram и должностей ЛПР.
- `sources.js` — реестр площадок, поисковых запросов и целевых направлений.
- `llm.js` — адаптер работы с Google Gemini API и OpenRouter.

### Модуль `backend/` (Express API)
Бэкенд отвечает за REST API, хранение данных в БД, WebSocket-оповещения и расписание. **Бэкенд ничего не знает про Tavily и Gemini.**

- `src/config/` — конфигурация порта, CORS и путей к данным.
- `src/db/` — управление базой данных (`leads.json`, `pipelines.json`, `settings.json`) и каталог сигналов.
- `src/routes/` — маршруты API (`/api/leads`, `/api/stats`, `/api/ai`, `/api/pipelines`, `/api/signals`, `/api/settings`).
- `src/services/` — бизнес-логика (`leadService.js`, `pipelineService.js`, `hunterService.js`, `schedulerService.js`).
- `src/ws/` — WebSocket-сервер для моментальной передачи найденных заказов в интерфейс.
- `src/server.js` — запуск HTTP/WS сервера.

### Модуль `frontend/` (UI)
- Минималистичный интерфейс (Swiss / Nordic SaaS) без эмодзи.
- Таблица лидов с фильтрами, скорингом и быстрым вызовом звонка/Telegram.
- Экран аналитики спроса и 4 ключевые KPI-метрики.

## Быстрый старт

### 1. Установка зависимостей
```bash
npm install
cd backend && npm install
cd ../ai && npm install
cd ../frontend && npm install
```

### 2. Настройка переменных окружения
Скопируйте `.env.example` в `backend/.env` и укажите ключи:
```env
PORT=8001
GEMINI_API_KEY=your_gemini_key
TAVILY_API_KEY=your_tavily_key
```

### 3. Запуск в режиме разработки
```bash
npm run dev
```
- Frontend: `http://localhost:5173`
- Backend API: `http://localhost:8001`
- WebSocket: `ws://localhost:8001`
